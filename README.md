# DocuTrackBST

## Descripción
Proyecto desarrollado en C# bajo arquitectura MVC que implementa un Árbol Binario de Búsqueda (BST) para modelar documentos y carpetas.

## Funcionalidades
- Inserción de nodos
- Búsqueda rápida
- Actualización de nodos
- Eliminación de nodos
- Recorridos InOrden
- Impresión ASCII del árbol
- Cálculo de altura
